\chapter{Danh mục sơ đồ Draw.io}

Báo cáo dùng 26 sơ đồ. Nguồn chỉnh sửa chuẩn nằm tại \path{latex/figures/drawio/} và bản render tại \path{latex/figures/rendered/}; mỗi basename trong bảng dưới đây ứng với một tệp \path{.drawio} trong thư mục nguồn và ba bản render \path{.pdf}, \path{.png}, \path{.svg} cùng tên. Báo cáo liên kết bản PDF vector; PNG/SVG dùng cho xem nhanh và tài liệu web. Toàn bộ tệp \path{.drawio} được sinh bằng ba script Python cùng thư mục: \path{core_gen.py} sinh sơ đồ 03--12, \path{usecase_gen.py} sinh sơ đồ 14--26, \path{sequence_style.py} sinh các sơ đồ tuần tự; vì vậy khi cần sửa sơ đồ phải sửa script rồi sinh lại chứ không chỉnh trực tiếp XML. Thuật ngữ trong sơ đồ đồng nhất với báo cáo và phân biệt lõi xác định, LLM, dữ liệu bền vững, state tạm cùng dịch vụ ngoài; sơ đồ nào dùng màu để mang nghĩa đều có bảng chú giải màu đặt ngay trong hình.

\chapter{Lệnh tái lập kiểm thử}

Các lệnh dưới đây được chạy từ đúng thư mục thành phần. Người thực hiện phải ghi commit, phiên bản runtime, cấu hình provider và trạng thái dịch vụ; không chép secret vào biên bản.

\begin{verbatim}
cd demo/backend
npm test
npm run test:ai

cd ../frontend
EXPO_PUBLIC_API_URL=http://127.0.0.1:3000 \
  npx expo export --platform web \
  --output-dir /tmp/perfin-web-final
\end{verbatim}

Để kiểm thử tích hợp, cần một PostgreSQL test riêng và Redis đang chạy. Migration phải được chạy trên database test; sau mỗi nhóm test phải kiểm tra rollback và dọn dữ liệu bằng fixture. Không dùng database phát triển cá nhân làm môi trường tự động.
