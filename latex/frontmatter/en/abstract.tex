\frontchapter{Abstract}

PERFIN is a personal finance management prototype that aims to reduce data-entry effort while preserving correctness and verifiability. The system ingests transactions from text, voice and receipt images; it normalizes input, extracts records and requests confirmation before writing to PostgreSQL. SQL and deterministic algorithms compute balances, budgets, trends, anomalies, cash-flow runway, recurring charges and goals; the LLM only interprets intent, fills parameters, asks clarifying questions when input is ambiguous, and narrates already-computed facts. The contribution is an architecture that separates language generation from the financial core, uses Redis for state management and BullMQ for task orchestration, together with an evaluation protocol for correctness and numeric faithfulness. Results reach 100/100 backend tests, a 31/31 local-parser quality gate and 23/23 full smoke tests; the application is packaged for web and Android; the demo dataset contains 5{,}265 transactions with provenance. Three quantitative experiments on this labeled dataset measure the core contribution: local-parser category classification reaches macro-F1 0.177, an ablation shows the LLM lifting macro-F1 to 0.561 (versus 0.192 for the parser) on the same stratified sample, and correction retrieval raises holdout accuracy from 0\% to 68.19\%. These figures justify the LLM-primary design with human confirmation. OCR/STT accuracy, numeric faithfulness and production readiness are still not demonstrated and remain measured only on a reproducible labeled dataset going forward.

\noindent\textbf{Keywords:} personal finance management, large language model, data analysis, PostgreSQL, Redis, verifiable systems.
