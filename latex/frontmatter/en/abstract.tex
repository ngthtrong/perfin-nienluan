\frontchapter{Abstract}

\textbf{Context:} Manual entry makes personal-finance histories incomplete or inconsistent, while figures generated by an LLM cannot be written directly to a ledger. \textbf{Objective:} This project builds PERFIN, a mobile prototype that accepts natural transaction input while preserving verifiable data and analysis. \textbf{Method:} Text, receipt images and speech are converted into typed drafts and written to PostgreSQL only after confirmation. Deterministic functions compute balances, trends, anomalies, cash flow, budgets and goals; the LLM only extracts intent and narrates facts. \textbf{Results:} The backend suite passes 182/182 tests, and the local parser obtains macro-F1 0.177 on 5,265 transactions. On the same 63-sentence sample, the parser and Gemini obtain 0.204 and 0.607. Correction retrieval reaches 68.19\% on sentences preselected because the parser was wrong; the 0\% baseline follows from this sampling rule and is not representative of the whole system. \textbf{Significance:} The architecture uses an LLM without replacing the data-and-algorithm core. OCR/STT accuracy and production readiness have not been established.

\vspace{0.5cm}
\noindent\textbf{Keywords:} personal finance management, large language model, data analysis, PostgreSQL, verifiable systems.
